Naming Conventions in GUILDA

Variable naming follows [variableType][size]_[variableDescription].

variableType size _ variableDescription

Variable Type × Size

type ↓
size →
(none)scalar
vcolumn vector
rrow vector
mmatrix

f: function handle (cell array if the variable itself is an array). Click any cell to load it into the generator below.

Naming Composition Examples

cv_Vequilibrium
ccomplex+vcolumn vector+_Vequilibrium

a complex-valued vector of equilibrium voltages

im_solution
iindex+mmatrix+_solution

a matrix of indices for an analysis result

r_gain
rreal+(no size: scalar)+_gain

Exceptional Naming Rules (Fixed Prefixes)

  • Table type
    tab_ + [variable description]  →  tab_bus_data

    Regardless of argument or output count.

  • GUILDA-specific class (cell array)
    a_ + [ClassName]  →  a_Controller

    A cell array of GUILDA class objects, named after the class.

  • Parameter class
    para_ + [data description]  →  para_generator

    Only for properties holding GUILDA's Parameter class.

Name-Value Options

Name-Value option names use UpperCamelCase, as in MATLAB (e.g. Method, Tolerance, MaxIteration). See API Design for the common options.
