Naming Conventions in GUILDAGUILDA の命名規則

Variable naming follows [variableType][size]_[variableDescription].

変数名は [variableType][size]_[variableDescription] の形。

variableType size _ variableDescription

type型 ↓
sizeサイズ →
(none)(なし)scalarスカラー

Exceptional Naming Rules (Fixed Prefixes)例外的な命名規則（固定の接頭辞）

  • Table variablestable 型の変数
    tab_ + [variable description][変数の説明]  →  tab_bus_data

    Regardless of argument or output count.引数や出力の数にかかわらず使用。

  • GUILDA objects in a cell arraycell 配列に入れた GUILDA のオブジェクト
    a_ + [ClassName][クラス名]  →  a_Controller

    A cell array of GUILDA class objects, named after the class.GUILDA のクラスのオブジェクトを並べた cell 配列。名前はクラス名から。

  • Parameter objectsParameter クラスのオブジェクト
    para_ + [data description][データの説明]  →  para_generator

    Only for properties holding GUILDA's Parameter class.GUILDA の Parameter クラスを保持するプロパティにだけ使用。

Naming of Name-Value OptionsName-Value オプションの命名

Name-Value option names use UpperCamelCase, as in MATLAB (e.g. Method, Tolerance, MaxIteration). See API Design for the common options.

Name-Value オプションの名前は MATLAB と同じく UpperCamelCase（例: Method、Tolerance、MaxIteration）。共通のオプションは API 設計 を参照。
