Writing rules記述の規則

  • Timeless時点に依存しない記述Write for a reader who starts with the current GUILDA version. No wording that needs knowledge of older versions: “v3”, “v4”, “no longer”, “renamed”, “formerly”. History goes only in the Update Log data.Fine: format versions of external files, math symbols, and a deprecation rule (how a deprecated name keeps working) that does not narrate past versions.現在の GUILDA から使い始める読者向けに記述。過去のバージョンの知識を前提とする表現（「v3」「v4」「旧」「従来」「以前」「廃止」など）は不可。経緯は Update Log のデータにだけ記載。可: 外部ファイルの形式のバージョン、数式の記号、過去を語らない非推奨の規則（非推奨の名前を動かし続ける仕組み）。
  • Terse簡潔な記述Japanese: 体言止め and bullet points rather than です・ます prose, so the point is caught at a glance. English equally terse; bullets where the structure changes.日本語は です・ます の文章より体言止めと箇条書き。要点が一目でわかる形に。英語も同じく簡潔に、構造が変わる箇所は箇条書き。
  • Two-column layouts2 列のレイアウトIf a two-column block wraps into many lines, first turn it into bullets; if still too long, use one column with the items stacked.改行の多い 2 列のブロックは、まず箇条書きに。それでも長ければ 1 列にして項目を縦に並べる。
  • Same structure同じ構造English and Japanese have the same blocks, bullets, and order.英語と日本語で同じブロック、箇条書き、順序。

Update Log entriesUpdate Log の項目

Each entry in _GUILDAdoc/database/list_UpdateLog.js is one object. The Home tab shows entries newest first, each card coloured by its type.

_GUILDAdoc/database/list_UpdateLog.js の各項目は 1 つのオブジェクト。Home タブは新しい順に表示し、種類ごとにカードを色分け。

{
  "title": "Add grid-forming inverter model",
  "date": "YYYY-MM-DD",
  "type": "added",
  "content": "One or two sentences on what changed for users."
}

The type field uses the Keep a Changelog categories:

type フィールドは Keep a Changelog の分類:

Type種類Use it for用途
addedA new feature, class, method or option.新しい機能、クラス、メソッド、オプション。
changedA change in the behaviour or interface of something that already exists.既存のものの動作やインターフェースの変更。
deprecatedSomething that still works but will be removed; name its replacement.まだ動くが今後削除されるもの。代わりを明記。
removedSomething removed.削除されたもの。
fixedA bug fix.バグの修正。

No type: neutral grey, no label. An unknown value: shown the same way, with a warning in the browser console.

type なし: ラベルなしの灰色で表示。未知の値: 同様に表示し、ブラウザのコンソールに警告。
