Write Tags in Source Comments

% comment prefix: removed
<@Summary>exact tag name, case-sensitive
Scale an input vector.value: runs until the next tag or the end of the block
  • ✓ <@Summary> tag
  • ✗ <Summary> plain text
  • ✗ <@ Summary> plain text
  • ⚠ <@summary> unknown tag

After the % and one space are removed, the rest of each line is kept: leading spaces, blank lines and text-art alignment survive. Source comments are read first because MATLAB's help renderer can change indentation.

Value shapes

Aa ¶ Summary Desc Notes …

Free text. Newlines, spaces and indentation are kept; ASCII diagrams render as monospace.

["…", "…"] Signatures Examples SeeAlso

JSON array of strings.

{…} or [{…}] Parameters Returns

JSON object or array of objects.

[{Class, Method, Condition}] Calls

JSON array of objects; must start with [.

  • ✓Summary = one sentence for reference tables.
  • ✓Desc = full text for the detail page. It does not replace a missing Summary in reference tables.
  • ✓Leave an optional tag empty when it does not apply; the exporter fills the type-appropriate empty value.
  • ✗Structured JSON must begin with [ or {: no MATLAB arrays or cell arrays.

Validation

⚠ Warning

  • Unknown or duplicate tag (the last duplicate wins)
  • Class has neither Summary nor Desc
  • Public, non-hidden method defined by the class has neither Summary nor Desc

✗ Error

  • Malformed structured JSON
  • Class reflection or file export failure

Diagnostics are stored in each class file and summarized in validation of the index. A tag that belongs to another target (for example <@Constructor> on a method) is not reported; it is simply not stored.

Use strict mode in automated checks. Warnings never fail the run; in strict mode they are also printed.

>> GUILDA.doc("update", true, "open", false, "strict", true);

Regenerating and Reviewing Documentation

  1. 1

    Add GUILDA to the path and rebuild the database.

    >> GUILDA.addpath();
>> GUILDA.doc("update", true, "open", false);
  2. 2

    Open the documentation.

    >> web(fullfile(GUILDA.pwd(), "_GUILDAdoc", "index.html"));
  3. 3

    Check database/list_Classes.js for the index summary, then in the Reference tab verify:

    • class links
    • summaries
    • inheritance markers
    • class pages
    • method pages
