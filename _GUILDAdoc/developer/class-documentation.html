Class Documentationクラスのドキュメント

Write MATLAB help comments next to the code. GUILDA.doc adds what the code declares and builds the Reference pages. Three tags cover the rest.

MATLAB のヘルプコメントをコードのすぐそばに書きます。GUILDA.doc がコードの宣言から読み取れる情報を加えて Reference のページを作ります。残りは 3 つのタグで補います。

How it worksしくみ

Nobody edits the Reference by hand. GUILDA.doc re-exports only the classes whose files changed.

Reference を手で編集することはありません。GUILDA.doc はファイルが変わったクラスだけを再エクスポートします。

Where comments goコメントを書く場所

Write ordinary MATLAB help comments. Each numbered comment lands in the matching place on the class page. Everything without a number is read from the code.

通常の MATLAB ヘルプコメントを書きます。番号の付いた各コメントは、クラスのページの同じ番号の場所に表示されます。番号のない部分はすべてコードから読み取られます。

Which tags使うタグ

A tag is only for what neither the code nor the help conventions can say. There are three.

タグは、コードからもヘルプの慣例からも表せない情報にだけ使います。タグは 3 つです。

TagタグClassクラスPropertyプロパティMethodメソッドUse when使う場面
ExamplesA short usage example helps. Markdown with fenced code blocks.短い使用例が役立つとき。フェンス付きコードブロックを含む Markdown で書きます。
DeprecatedThe member will be removed. The text names the replacement.そのメンバーが削除される予定のとき。本文で代替を示します。
TypeThe declaration cannot state the class, for example an untyped property that holds a SolverPF.宣言でクラスを示せないとき。たとえば SolverPF を保持する型指定のないプロパティです。

Put tags at the end of the comment block, after the description and the See also line. Write % <@Tag> value; a value can continue on the next % lines, up to the next tag or the end of the block.

タグはコメントブロックの最後、説明と See also 行の後に置きます。% <@Tag> value と書きます。値は次のタグかブロックの終わりまで、続く % 行に書き足せます。

Call graph on the method pageメソッドのページの呼び出しグラフ

For the methods of the classes under _GUILDAsystem, the exporter reads the source with mtree, without running it, and stores in database/list_CallGraph.js which properties and methods each one uses. The file is rebuilt on every export. Local functions and private/ helpers have no node: what they use counts for the method that calls them.

_GUILDAsystem の下のクラスのメソッドについて、エクスポーターはソースを実行せずに mtree で読み、各メソッドが使うプロパティとメソッドを database/list_CallGraph.js に保存します。このファイルはエクスポートのたびに作り直されます。ローカル関数と private/ のヘルパーにはノードがなく、それらが使うものは呼び出し元のメソッドが使うものとして数えます。

Line線Meaning意味
Solid実線Certain: the object itself, a declared class (property validator or arguments block), a constructor or a Class.member reference.確実: オブジェクト自身、宣言されたクラス（プロパティの検証または arguments ブロック）、コンストラクター、Class.member による参照。
Dashed破線Inferred, in this order: assignments and obj.p = value, the argument of a helper, the naming rule, or the only class with a member of that name.推定。次の順で判断します: 代入と obj.p = value、ヘルパーの引数、命名規則、その名前のメンバーを持つ唯一のクラス。
Dotted, with branches点線（枝分かれ）The class is not determinable from the source. Every class with that member is listed; none is chosen.ソースからクラスを決められません。そのメンバーを持つクラスをすべて並べ、どれも選びません。

The chart is a reading aid, not a proof. A link shows the class the code names, not the subclass that runs: a call through Component does not list the override in Bus or in a model. An inferred link can be wrong, and calls through function handles held in properties, obj.(name), feval and eval have no target (the page says when a method uses the last three). Implicit calls, such as a conversion in "text" + obj or a destructor, do not appear. Functions outside a class are not followed.

このグラフは読むための補助であり、証明ではありません。リンクが示すのはコードが名指しするクラスで、実際に実行されるサブクラスではありません。Component を通した呼び出しには、Bus やモデルでのオーバーライドは載りません。推定したリンクは誤ることがあります。プロパティに保持した関数ハンドル、obj.(name)、feval、eval を通した呼び出しには呼び出し先がありません（メソッドが後の 3 つを使う場合はページにそう表示されます）。"text" + obj での変換やデストラクターなどの暗黙の呼び出しは現れません。クラスの外の関数はたどりません。

What the exporter checksエクスポーターのチェック

Every run prints one line per exported class and a summary. A problem is reported where the member is defined, not again for each subclass.

実行するたびに、エクスポートしたクラスごとに 1 行と集計が表示されます。問題はメンバーを定義した場所で 1 回だけ報告され、サブクラスごとに繰り返されることはありません。

LevelレベルCheckチェック内容
Warning警告A removed tag, with its replacement (see Removed tags).An error with "strict", true.廃止したタグ。代わりの書き方も示します（廃止したタグを参照）。"strict", true ではエラーになります。
Warning警告A class, or its own public non-hidden method or property, has no H1 line.クラス、またはそのクラス自身の hidden でない公開メソッドやプロパティに H1 行がない。
Warning警告A <@Deprecated> tag with no text.The text must name the replacement.本文のない <@Deprecated> タグ。本文で代替を示す必要があります。
Warning警告An unknown tag, or the same tag twice (the last value is used).未知のタグ、または同じタグの重複（最後の値が使われます）。
Warning警告A method declared in the classdef with no implementation file.classdef で宣言されているのに実装ファイルがないメソッド。
CoverageカバレッジDocumented / total for classes, public methods and public properties. Documented means it has an H1 line.Shown at the top of the Reference tab. Undocumented classes get a no docs marker there.クラス、公開メソッド、公開プロパティそれぞれの「記述済み / 総数」。記述済みとは H1 行があることです。Reference タブの上部に表示されます。記述のないクラスにはそこで no docs の印が付きます。

With GUILDA.doc("strict", true) the run fails when there are errors.

GUILDA.doc("strict", true) では、エラーがあると実行が失敗します。
