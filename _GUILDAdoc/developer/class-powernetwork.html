Class: クラス: PowerNetwork

The root of the model: it holds the buses, branches, and global controllers of one grid, the system base values, and the default settings of every analysis, and it is the entry point that runs them.

モデルの根です。1 つの系統の母線・ブランチ・広域制御器、系統の基準値、各解析の既定設定を持ち、すべての解析を実行する入口になります。

Role役割

PowerNetwork owns the topology (which buses, branches, and global controllers exist), the system base in tab_parameter.base (Hz, baseMVA), the solver objects solver_*, and the network-wide OPF terms. Every analysis starts here: the method reads its settings from a solver object, hands the network to it, and returns a result object. It is not where the numbers are: bus voltages belong to Bus, the model equations to Component and the controllers, and the numerical methods to the Solver* classes. Results are returned, never stored in the network. The one exception is initialize, which writes the equilibrium into the buses, components, and controllers.

PowerNetwork はトポロジー（どの母線・ブランチ・広域制御器があるか）、tab_parameter.base の系統基準値（Hz、baseMVA）、ソルバーオブジェクト solver_*、ネットワーク全体の OPF 項を持ちます。すべての解析はここから始まります。メソッドはソルバーオブジェクトから設定を読み、ネットワークを渡し、結果オブジェクトを返します。数値そのものは持ちません。母線電圧は Bus、モデルの方程式は Component と制御器、数値解法は Solver* クラスが担います。結果は返り値であり、ネットワークには保存しません。例外は initialize で、平衡点を母線・機器・制御器に書き込みます。

Subclassesサブクラス

A network class in _GUILDAobject/+network/ is a subclass of PowerNetwork whose constructor builds a ready-made grid, usually with PowerNetwork.import_csv(folder, Network=obj) from the CSV folders next to its class file. They add no methods. To add one, see Model Implementation: Branches and networks.

_GUILDAobject/+network/ のネットワーククラスは PowerNetwork のサブクラスで、コンストラクタが既成の系統を組み立てます。多くはクラスファイルの隣の CSV フォルダから PowerNetwork.import_csv(folder, Network=obj) で読み込みます。メソッドは追加しません。追加方法はモデル実装: ブランチとネットワークを参照してください。
