Time Simulation Feature Design時間応答シミュレーション機能の設計

net.simulate integrates the differential-algebraic equations (DAE) of the network over time from the equilibrium of net.initialize, under the disturbances of the given scenarios (Scenario). This page follows one call: public method → SolverODE → ResultODE.

net.simulate: net.initialize の平衡点から出発し、与えたシナリオ (Scenario) の外乱のもとでネットワークの微分代数方程式 (DAE) を時間積分する機能。このページの対象は 1 回の呼び出し: 公開メソッド → SolverODE → ResultODE。

What the feature does and how to call it機能の目的と呼び出し方

The time span is split into phases: intervals with an unchanged set of active disturbances.

  • One phase: one call of the MATLAB ode object on the DAE of the network in that phase (faulted buses and tripped units removed, opened branches left out of the admittance matrix).
  • Start of the next phase: the state at the end of a phase, after the changes of the next phase.

時間区間をフェーズに分割。フェーズ: 有効な外乱の組が変わらない区間。

  • 1 フェーズ: そのフェーズのネットワーク (地絡した母線とトリップした機器を除き、開放したブランチをアドミタンス行列から除いたもの) の DAE を MATLAB の ode オブジェクトで 1 回求解
  • 次のフェーズの初期値: フェーズ終了時の状態 + 次のフェーズの変化
[result, flag, output] = net.simulate(time, sc1, sc2, ..., Name, Value)
[result, flag, output] = net.simulate(sc, Name, Value)
sc = Scenario(tag, Time=…, Options=…, Judge=…, Description=…)
sc.add_fault(bus, [t_start, t_end])            % also add_trip, add_open_branch, add_offset, add_input
net.add_scenario(sc)
verdict = sc.judge(result)
  • time: [t0, tend] in seconds with finite t0 < tend, [], or left out (net.simulate(sc, ...)). Without a time:
    • the Time of the scenarios;
    • else [0, 30·ceil(tmax/10)], tmax = latest disturbance time (10 s more when that equals tmax);
    • without disturbances, [0, 10].
  • time: 秒単位の [t0, tend] (有限で t0 < tend)、[]、または省略 (net.simulate(sc, ...))。省略時:
    • シナリオの Time
    • なければ [0, 30·ceil(tmax/10)]。tmax は外乱の最も遅い時刻 (それが tmax と等しければ 10 s 延長)
    • 外乱がなければ [0, 10]
  • Scenarios: the leading Scenario arguments, each added to this network (net.add_scenario).
    • None: the response without disturbance. Several: disturbances combined.
    • After the first non-Scenario argument: Name-Value options.
    • Different Time, or different values of one stored option: error, unless the call gives the time or the option.
    • Verdict: not an output; call sc.judge(result) (default Scenario.out_of_step).
  • シナリオ: 先頭に並べた Scenario 引数。それぞれこのネットワークに追加済み (net.add_scenario)
    • なし: 外乱のない応答。複数: 外乱を合成
    • 最初の Scenario 以外の引数から後ろ: Name-Value オプション
    • Time や保存されたオプションの値がシナリオ間で異なる場合: エラー (呼び出しで時間やそのオプションを与えた場合を除く)
    • 判定: 出力に含まれない。sc.judge(result) を呼び出し (既定は Scenario.out_of_step)

Disturbances given as a ScenarioScenario で与える外乱

A scenario holds a list of disturbances (sc.tab_disturbance), each with its own time span and tag.

  • Tag: the column of the disturbance in the phase table. Unique in the scenario and in one run; not t1, t2, Properties, Row, Variables, empty, or NoAction followed by digits. Defaults of the add_* methods: fault<n>, open<n>, ...
  • Buses, branches and units: named by tag; checked against the network when added and again in SIM-05.
  • sc.add_disturbance(tag, Name=Value): takes the fields below; several kinds can be combined in one disturbance.

シナリオ: 外乱の一覧 (sc.tab_disturbance) を保持。外乱ごとに時間区間とタグ。

  • タグ: フェーズ表での外乱の列名。シナリオ内と 1 回の実行内で一意。t1、t2、Properties、Row、Variables、空文字、NoAction + 数字は使用不可。add_* メソッドの既定のタグ: fault<n>、open<n> など
  • 母線・ブランチ・機器: タグで指定。追加時と SIM-05 でネットワークと照合
  • sc.add_disturbance(tag, Name=Value): 以下のフィールドを受け取り、1 つの外乱で複数の種類の組み合わせも可能
Field (method)フィールド (メソッド)Effect during the disturbance外乱中の作用
TimeSpan[s] [t_start, t_end], or t_start alone for an offset. A fault, trip, branch opening or input needs t_start < t_end. Default of add_disturbance [0, 10].[s] [t_start, t_end]。オフセットだけなら t_start のみ。地絡、トリップ、ブランチの開放、入力には t_start < t_end が必要。add_disturbance の既定値は [0, 10]。

  • Scenarios are not model data: adding, removing or editing them does not make the equilibrium stale.
  • Scenario.import_csv, Scenario.export_csv: several scenarios, one row per disturbance.
  • Deprecated ODEevent(tag, net, Name, Value) (_VersionSupport/): returns a scenario with one disturbance, already added to net.
  • シナリオはモデルのデータではない: 追加・削除・編集しても平衡点は古くならない
  • Scenario.import_csv、Scenario.export_csv: 複数のシナリオを外乱 1 つにつき 1 行で読み書き
  • 非推奨の ODEevent(tag, net, Name, Value) (_VersionSupport/): 外乱を 1 つ持ち net に追加済みのシナリオを返却

Preconditions for the call呼び出しの前提条件

  • net.initialize() has run, with no edit since that changes the equilibrium (see Class Design: Handling of model edits). Out-of-date function handles f_*: rebuilt automatically.
  • net.initialize() を実行済みで、その後に平衡点を変える編集がないこと (クラス設計: モデル編集の扱い を参照)。古くなった関数ハンドル f_* は自動で再構築
  • Every scenario belongs to this network and the tags of its disturbances exist in it now, and every unit a global controller controls is on this network.
  • すべてのシナリオがこのネットワークに属し、その外乱のタグが現在のネットワークに存在すること。広域制御器が制御する機器がすべてこのネットワーク上にあること。
  • The mass matrices of all components and controllers are constant (tools.read_mass).
  • すべての機器と制御器の質量行列が定数であること (tools.read_mass)。

Processing steps in detail処理ステップの詳細

  • Each step: one requirement of the feature. Steps marked on the left run once per phase.
  • n_x, n_v (= 2 × number of buses), n_u: numbers of states, bus voltage variables and component inputs of net.get_variable_map(). n_sim: length of the simulator vector (see Data produced).
  • 各ステップ: この機能の 1 つの要件。左に印のあるステップはフェーズごとに実行
  • n_x、n_v (= 2 × 母線数)、n_u: net.get_variable_map() の状態、母線電圧変数、機器入力の数。n_sim: シミュレータのベクトルの長さ (生成されるデータを参照)

  5. SIM-05 SolverODE.solve → Scenario.compile, check_islands

    What it does処理内容
    • Checks that each scenario belongs to this network, and its disturbances against the network as it is now (validate).
    • Combines the disturbances of all the scenarios (tags unique in the run); without disturbances, adds one empty one ("NoAction" at t0).
    • Warns for disturbances outside time; cuts the span at every disturbance time (getTimeSpan) and marks the active disturbances of each phase. A phase without an active disturbance gets its own NoAction<k>.
    • Builds once what each phase applies: the faulted buses, tripped units, opened branches; per component, the state offset of the disturbances that start in the phase (all active ones in the first phase) and one input function of the phase time, shifted so that each disturbance function receives the time since its own t_start.
    • check_islands: stops if the opened branches of a phase leave buses without any component.
    • 各シナリオがこのネットワークに属するか、その外乱が現在のネットワークと整合するかを検査（validate）
    • すべてのシナリオの外乱を合成（タグは実行内で一意）。外乱がなければ空の外乱（t0 の "NoAction"）を 1 つ追加
    • time の外にある外乱を警告。外乱の時刻ごとに区間を分割（getTimeSpan）し、各フェーズで有効な外乱に印。有効な外乱のないフェーズには専用の NoAction<k>
    • 各フェーズで適用する内容を一度だけ構築: 地絡母線、トリップ機器、開放ブランチ。機器ごとに、そのフェーズで始まる外乱（最初のフェーズでは有効なものすべて）の状態オフセットと、フェーズ内時刻の 1 つの入力関数。入力関数は、各外乱の関数にその外乱の t_start からの経過時間が渡るようにシフト
    • check_islands: あるフェーズの開放ブランチで機器のない母線が切り離されるなら停止
    What it reads読み取る情報
    sc.tab_disturbance (TimeSpan, FaultBus, TripUnit, OpenBranch, Offset*, Input*), sc.a_PowerNetwork; bus, branch and component tags母線・ブランチ・機器のタグ, sv_x, sv_u
    Returns or changes戻り値・変更する値
    tab_phase (table, one row per phase: t1, t2 [s], one logical column per disturbance表。フェーズごとに 1 行: t1, t2 [s] と、外乱ごとの論理値の列), sct_phase (per phaseフェーズごと: t1, t2, sv_event, sv_fault, sv_trip, sv_open, c_Xoffset, c_Uoffset)

    • Records, by name, which inputs the outputs of the controllers under each one drive.
    • Registers restore_working_data with onCleanup.
    • 各広域制御器の制御対象がこのネットワーク上にあるか確認
    • シミュレータのベクトルに番号付け: 母線ごと・機器ごとに機器の状態と入力、続いてその局所制御器の状態と入力を深さ優先で（AVR または "local" の制御器、AVR の下の PSS、ガバナの順）。次に各広域制御器の状態。最後に各母線の Vre, Vim, Ire, Iim
    • 各機器・制御器について、その下の制御器の出力が駆動する入力を名前で記録
    • onCleanup で restore_working_data を登録

  10. SIM-10 SolverODE.solve → SolverODE.set_admittance, SolverODE.set_offsets

    What it does処理内容
    • Leaves the branches opened in this phase out of the admittance matrix (Ybus minus the matrix of each opened branch).
    • Rebuilds the matrix only when the set of opened branches changes, so a branch is reconnected at the phase after its t_end.
    • Puts the state offsets and the input function of the phase, built by SIM-05, on each component.
    • このフェーズで開放するブランチをアドミタンス行列から除外（Ybus から開放ブランチごとの行列を減算）
    • 行列の再構築は開放ブランチの組が変わったときのみ。ブランチの再接続は t_end の後のフェーズ
    • SIM-05 で構築したフェーズの状態オフセットと入力関数を各機器に設定

  11. SIM-11 SolverODE.solve → SolverODE.initial_condition

    What it does処理内容
    • Marks the faulted buses and the tripped components.
    • Builds the full mass matrix (component and controller blocks from tools.read_mass, zero rows for inputs and bus variables).
    • Builds the selection matrices that remove the variables of faulted buses (4 each) and tripped components (states and inputs).
    • Start value: first phase, the equilibrium plus the offsets; later phases, the state carried over plus the offsets of this phase.
    • 地絡母線とトリップ機器に印
    • 全体の質量行列を構築（機器と制御器のブロックは tools.read_mass、入力と母線変数は 0 の行）
    • 地絡母線の変数（各 4 個）とトリップ機器の変数（状態と入力）を除く選択行列を構築
