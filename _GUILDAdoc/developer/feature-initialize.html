Initialization初期化

net.initialize() turns an operating point (a power flow, an AC optimal power flow, or the equilibria the components already hold) into the equilibrium of every bus, component, local controller, and global controller, checks it, and resets the edit log. Every dynamic analysis starts from this equilibrium.

net.initialize() は、運転点（潮流計算、交流の最適潮流計算、または機器がすでに持つ平衡点）を、すべての母線・機器・局所制御器・広域制御器の平衡点として設定し、検査したうえで編集ログをリセットします。動的な解析はすべてこの平衡点から始まります。

Side effects and caches副作用とキャッシュ

  • Written: the equilibrium properties above; the f_* handle caches that were not up to date (INIT-02); l_isSlack of the bus that the power flow selects when none is set (kept after a successful call); the gain of controller.local_LQR.
  • Edit state: l_staleEquilibrium is set at INIT-05 and cleared at INIT-13 together with str_flag = "initialized" and the edit log of every layer. A call that stops between them leaves it set.
  • Later edits: the edit log decides what becomes stale (see Class Design: Edit handling). Nothing re-runs initialize automatically: simulate, linearize, and get_sys stop with GUILDA:PowerNetwork:EquilibriumStale, and the continuation power flow with GUILDA:SolverCPF:StaleEquilibrium. After edits of dynamics parameters only, initialize(Method="equilibrium") keeps V and I and recomputes the states and inputs.
  • Network frequency: an edit of Hz rebuilds the handles at the next analysis but does not need a new initialize.
  • 書き込むもの: 上の平衡点のプロパティ、最新でなかった f_* ハンドルのキャッシュ（INIT-02）、スラック母線が未設定のとき潮流計算が選ぶ母線の l_isSlack（呼び出しが成功すれば残ります）、controller.local_LQR のゲイン。
  • 編集状態: l_staleEquilibrium は INIT-05 で設定され、INIT-13 で str_flag = "initialized" と全レイヤーの編集ログのリセットとともに解除されます。その間で停止した呼び出しでは設定されたままになります。
  • 後からの編集: 何が古くなるかは編集ログで決まります（Class Design: Edit handling を参照）。initialize が自動で再実行されることはありません。simulate、linearize、get_sys は GUILDA:PowerNetwork:EquilibriumStale で、連続潮流計算は GUILDA:SolverCPF:StaleEquilibrium で停止します。動特性パラメータだけを編集した後は、initialize(Method="equilibrium") が V と I を保ったまま状態と入力を計算し直します。
  • 系統周波数: Hz の編集では次の解析でハンドルが再構築されますが、initialize のやり直しは不要です。

A new model takes part in initialization through its get_equilibrium (see Model Implementation: Contracts):

新しいモデルは get_equilibrium を通じて初期化に参加します（Model Implementation: Contracts を参照）。

ModelモデルMust implement実装すべきもの
Component [x, u] = get_equilibrium(obj, c_V, c_I, r_P, r_Q), always called with all four arguments. x and u have the sizes of sv_x and sv_u, and at (x, V, u) the model holds: fcn_dx = 0 and fcn_I = c_I. The power-flow settings P, Q (NaN Q for a voltage-controlling unit) and operation.baseMVA decide what the component receives. [x, u] = get_equilibrium(obj, c_V, c_I, r_P, r_Q)。常に 4 つの引数で呼ばれます。x と u は sv_x と sv_u の大きさで、(x, V, u) でモデルが fcn_dx = 0 と fcn_I = c_I を満たすこと。機器が受け取る値は潮流計算の設定 P、Q（電圧を制御する機器は Q を NaN）と operation.baseMVA で決まります。
LocalController get_equilibrium(obj, V, u) with no output: write rv_Xequilibrium and rv_Uequilibrium, and call the nested controller. At the equilibrium the outputs must equal the inputs of the component they drive. 出力のない get_equilibrium(obj, V, u)。rv_Xequilibrium と rv_Uequilibrium を書き込み、入れ子の制御器を呼びます。平衡点では、出力が駆動する機器の入力と等しくなければなりません。
GlobalController [x, u] = get_equilibrium(obj). It runs before the buses and components are set (INIT-06), so it must not read their new equilibrium. Its outputs must be zero at the equilibrium, because they are added to the inputs of the controlled units. [x, u] = get_equilibrium(obj)。母線と機器の設定より前（INIT-06）に実行されるため、それらの新しい平衡点を読んではいけません。出力は制御対象の入力に加算されるので、平衡点ではゼロでなければなりません。

Check a new model with comp.validate() or con.validate(); initialize reports the remaining residuals with EquilibriumResidual.

新しいモデルは comp.validate() または con.validate() で確認します。残った残差は initialize が EquilibriumResidual で報告します。
