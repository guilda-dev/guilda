Debugging Guideデバッグガイド

Where to look when something goes wrong: for each stage, the entry method and solver class, the result fields to read, the settings that change it, and the messages you are likely to see. The source of a method is linked from its class reference page.

うまくいかないときに見る場所をまとめます。段階ごとに、入口のメソッドとソルバークラス、読むべき結果のフィールド、挙動を変える設定、よく出るメッセージを示します。メソッドのソースはクラスリファレンスの各ページからたどれます。

Where to look first最初に見る場所

Reading a messageメッセージの読み方

  • Every GUILDA message has an ID GUILDA:<Object>:<Key>. Its text is the entry <Key> in _GUILDAsystem/_auxiliary/SystemTools/GUILDA/en/<Object>.xml; search the code for the ID to find where it is raised.
  • GUILDA のメッセージには GUILDA:<Object>:<Key> という ID があります。本文は _GUILDAsystem/_auxiliary/SystemTools/GUILDA/en/<Object>.xml の <Key> 項目です。発生箇所はコードを ID で検索して探します。
  • An error from error(msg(...)) carries the text only: ME.identifier is empty, so check flag or result.l_success rather than catching by identifier. A warning has the ID as identifier (lastwarn, warning("off", id)).
  • error(msg(...)) のエラーは本文だけを持ち、ME.identifier は空です。識別子で捕まえるのではなく、flag や result.l_success を確かめます。警告は ID を識別子に持ちます（lastwarn、warning("off", id)）。
  • Warnings and INFO lines can be hidden by Message.ShowWarning and Message.ShowInfo of GUILDA.setting; turn them on while debugging.
  • 警告と INFO は GUILDA.setting の Message.ShowWarning と Message.ShowInfo で非表示にできます。デバッグ中は表示にします。
  • An error that says to run net.initialize() first lists the edits that made the model stale; net.sct_stale (and sct_stale of each object) shows the same.
  • 先に net.initialize() を実行するよう求めるエラーには、モデルを古くした編集が並びます。net.sct_stale（各オブジェクトの sct_stale）でも同じ内容を確認できます。
