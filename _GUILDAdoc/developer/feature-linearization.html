Feature: Linearization機能: 近似線形化

net.linearize linearizes the network DAE at the equilibrium (or at a given point) and returns the unreduced Jacobian blocks as a ResultLIN; result.get_ss and net.get_sys turn them into a state-space model. This page follows one call through SolverLIN and the get_sys of each layer.

net.linearize はネットワークの DAE を平衡点 (または指定した点) のまわりで線形化し、縮約前のヤコビアンのブロックを ResultLIN として返します。result.get_ss と net.get_sys はそれを状態空間モデルにします。このページでは、SolverLIN と各層の get_sys を通る 1 回の呼び出しを順に追います。

Purpose and entry point目的と入口

The result is the linear DAE in deviations from the point, in the order of net.get_variable_map() (see Class Design, Variable order), with x the states, v = [Vre1; Vim1; Vre2; …] the bus voltages and u the component inputs:

結果は点からの偏差で表した線形 DAE で、net.get_variable_map() の順に並びます (クラス設計: 変数の順序 を参照)。x は状態、v = [Vre1; Vim1; Vre2; …] は母線電圧、u は機器の入力です。

E dx/dt = Axx x + Axv v + Bx u
      0 = Avx x + Avv v + Bv u      % current balance Y v − I of each bus
[result, flag, output] = net.linearize(Name, Value)
sys = result.get_ss(Algorithm, Coordinate=…, Input=…, Output=…)
[sys, flag, output] = net.get_sys(Name, Value)    % net.linearize + result.get_ss

Name-Value options and defaultsName-Value オプションと既定値

The defaults are the properties of net.solver_LIN (a SolverLIN, class defaults; no GUILDA.config entry). A Name-Value option overrides them for this call only (SolverLIN.OptionMap, tools.resolve_options); net.reset_solver() replaces the solver. See API Design.

既定値は net.solver_LIN (SolverLIN) のプロパティで、クラスの既定値です (GUILDA.config の項目はありません)。Name-Value オプションはその呼び出しに限って上書きします (SolverLIN.OptionMap、tools.resolve_options)。net.reset_solver() はソルバーを置き換えます。API 設計 を参照してください。

Preconditions前提条件

  • net.initialize() has run and nothing that changes the equilibrium was edited since, also when a Point is given (see Class Design, Edit handling). Out-of-date f_* handles are rebuilt automatically.
  • net.initialize() を実行済みで、その後に平衡点を変える編集がないこと (Point を与えた場合も同じ。クラス設計: 編集の扱い を参照)。古い f_* ハンドルは自動で作り直されます。
  • No component equation depends on the current I (the ports are V in, I out).
  • 機器の式が電流 I に依存しないこと (端子は V が入力、I が出力)。
  • A Point vector has one finite value per row of the variable map.
  • Point のベクトルは変数マップの行ごとに 1 つの有限な値を持つこと。

新しいモデルは モデルの実装 の契約を通して線形化されます。ヤコビアンの関数はシミュレーションと同じもので、t = 0 と点で呼ばれます。この機能が使うもの:

ComponentJacobi_dx, Jacobi_I, Jacobi_Y returning [∂/∂x, ∂/∂V, ∂/∂I, ∂/∂u] (numerical differentiation without them); the blocks of I must be zero. fcn_Mass is E. fcn_dx and fcn_I give the residual (LIN-14). sv_x, sv_u, sv_y name the states, inputs and outputs; an output with a state's name becomes Y_<name>.[∂/∂x, ∂/∂V, ∂/∂I, ∂/∂u] を返す Jacobi_dx、Jacobi_I、Jacobi_Y (なければ数値微分)。I のブロックは 0 でなければなりません。fcn_Mass が E になります。fcn_dx と fcn_I は残差に使います (LIN-14)。sv_x、sv_u、sv_y は状態・入力・出力の名前で、状態と同名の出力は Y_<name> になります。
