Linearization Feature Design近似線形化機能の設計

net.linearize linearizes the network DAE at the equilibrium (or a given point). Output: the unreduced Jacobian blocks as a ResultLIN; result.get_ss and net.get_sys turn them into a state-space model. This page follows one call through SolverLIN and the get_sys of each layer.

net.linearize: ネットワークの DAE を平衡点 (または指定した点) のまわりで線形化する機能。出力は縮約前のヤコビアンのブロックを持つ ResultLIN。result.get_ss と net.get_sys で状態空間モデルに変換。このページの対象は、SolverLIN と各層の get_sys を通る 1 回の呼び出し。

What the feature does and how to call it機能の目的と呼び出し方

Result: the linear DAE in deviations from the point, in the order of net.get_variable_map() (see Class Design: Order of state and input variables); x states, v = [Vre1; Vim1; Vre2; …] bus voltages, u component inputs:

結果: 点からの偏差で表した線形 DAE。並びは net.get_variable_map() の順 (クラス設計: 状態・入力変数の順序 を参照)。x は状態、v = [Vre1; Vim1; Vre2; …] は母線電圧、u は機器の入力。

      0 = Avx x + Avv v + Bv u      % current balance Y v − I of each bus

Preconditions for the call呼び出しの前提条件

  • net.initialize() has run, with no edit since that makes a layer stale, a network Hz edit included, also when a Point is given (see Class Design: Handling of model edits). initialize builds the f_* handles.
  • net.initialize() を実行済みで、その後に層を古くする編集（ネットワークの Hz の編集も含む）がないこと (Point を与えた場合も同じ。クラス設計: モデル編集の扱い を参照)。f_* ハンドルは initialize が作成
  • No component equation depends on the current I (the ports are V in, I out).
  • 機器の式が電流 I に依存しないこと (端子は V が入力、I が出力)。
  • A Point vector has one finite value per row of the variable map.
  • Point のベクトルは変数マップの行ごとに 1 つの有限な値を持つこと。

  7. LIN-07 SolverLIN.solve → Bus.get_sys("port", "V2I")

    What it does処理内容

    • The solver keeps the current rows and the outputs separately, with the columns of V and of the component inputs (controller inputs left out).

  19. LIN-19 caller呼び出し側 → ResultLIN.get_ss

    What it does処理内容
    Reduces the blocks to a descriptor model:
    • via_kron: eliminates v (A = Axx − Axv·Avv⁻¹·Avx);
    • via_feedback: connects the bus models in I-to-V form (i2v_full) through the admittance matrix, absorbs buses without an I-to-V form into it, then closes the global controllers (feedback);
    • via_dae: keeps v in the chosen coordinates (coordinate_filter).
    • select_output, input_index: apply Output and Input.
    • Stops for "NotFinite", and for "SingularAvv" except with "DAE".
    ブロックをディスクリプタ形式のモデルに縮約:
    • via_kron: v を消去 (A = Axx − Axv·Avv⁻¹·Avx)
    • via_feedback: I-to-V 形式の母線モデル (i2v_full) をアドミタンス行列で接続。I-to-V 形式のない母線はアドミタンス行列に吸収。最後に広域制御器を閉ループ化 (feedback)
    • via_dae: v を指定した座標で保持 (coordinate_filter)
    • select_output、input_index: Output と Input を適用
    • 停止: "NotFinite"、および "DAE" 以外での "SingularAvv"
    What it reads読み取る情報
    rm_*, sct_model, tab_variable, options, output.s_issue
    Returns or changes戻り値・変更する値
    sys (dss; sizes inサイズは Data生成されるデータ)
