_GUILDAsystem/on pathパス上

The modeling framework.モデリングのフレームワークです。

Belongs here置くもの
Base classes that define what a network, bus, branch, component, and controller are; the classes that perform analysis; general helper functions; compatibility wrappers for old names.ネットワーク、母線、ブランチ、機器、制御器を定義する基底クラス、解析を行うクラス、汎用の補助関数、旧名称のための互換ラッパー。
Core classesコアクラス
@PowerNetwork, @Bus, @Branch, @Component, @LocalController, @GlobalController.
Support classes補助クラス
In _auxiliary/: class categories (LayerPackage, PowerSystemModel, auxiliary) and @Parameter; solvers (@SolverPF, @NewtonRaphsonMethod, @SolverOPF, @SolverCPF, @SolverODE, @EventODE, @ProgressODE, @SolverLIN); result classes (@ResultBase and its subclasses @ResultPF, @ResultOPF, @ResultCPF, @ResultODE, @ResultLIN); drawing (@DrawerNetDiagram)._auxiliary/ 内: クラスカテゴリ（LayerPackage、PowerSystemModel、auxiliary）と @Parameter、ソルバー（@SolverPF、@NewtonRaphsonMethod、@SolverOPF、@SolverCPF、@SolverODE、@EventODE、@ProgressODE、@SolverLIN）、結果クラス（@ResultBase とそのサブクラス @ResultPF、@ResultOPF、@ResultCPF、@ResultODE、@ResultLIN）、描画（@DrawerNetDiagram）。
Otherその他
+tools/ helpers; _VersionSupport/ wrappers for old names (e.g. Continuation_Power_Flow → net.calculate_continuation_powerflow, CsvNetHandler → PowerNetwork.import_csv / net.export_csv).+tools/ の補助関数、_VersionSupport/ の旧名称用ラッパー（例: Continuation_Power_Flow → net.calculate_continuation_powerflow、CsvNetHandler → PowerNetwork.import_csv / net.export_csv）。
Relation関係
Depends on no concrete model in _GUILDAobject, so models can be added or removed without touching the framework. _GUILDAobject/on pathパス上

Concrete models that users put into a network.ユーザーがネットワークに組み込む具体的なモデルです。

Belongs here置くもの
Model classes, grouped into packages by kind (branch / component / controller / network), with sub-packages for model families that share a base class. A network template is a class that builds the network in its constructor, usually a class folder with data subfolders per element type.種類（branch / component / controller / network）ごとにパッケージにまとめたモデルクラス。基底クラスを共有するモデル群はサブパッケージにまとめます。ネットワークテンプレートはコンストラクタでネットワークを組み立てるクラスで、通常は要素の種類ごとにデータのサブフォルダを持つクラスフォルダです。
Networksネットワーク
Bundled templates include IEEE9bus, IEEE14bus (the MATPOWER case14 data), IEEE14bus_NoTap (transformer taps at 1), IEEE14bus_lossless (R = 0), IEEE68bus, and the IEEJ standard models IEEJ_EAST10, IEEJ_EAST30, IEEJ_WEST10, IEEJ_WEST30 (a peak/ and a night/ folder each, chosen with Section). Each constructor loads its own folder with PowerNetwork.import_csv(dir, Network=obj).同梱のテンプレートには IEEE9bus、IEEE14bus（MATPOWER の case14 のデータ）、IEEE14bus_NoTap（変圧器タップを 1 に固定）、IEEE14bus_lossless（R = 0）、IEEE68bus、電気学会標準モデル IEEJ_EAST10、IEEJ_EAST30、IEEJ_WEST10、IEEJ_WEST30（それぞれ peak/ と night/ のフォルダを持ち、Section で選択）があります。各コンストラクタは PowerNetwork.import_csv(dir, Network=obj) で自身のフォルダを読み込みます。
Relation関係
Every model inherits from a base class in _GUILDAsystem.すべてのモデルは _GUILDAsystem の基底クラスを継承します。

Inside a class or package folder, a subfolder without an @ or + prefix is not on the path: use it for data or archived code only. A class folder keeps one method per file; a small model may be a single classdef file instead.クラスフォルダやパッケージフォルダの中で、@ や + の接頭辞がないサブフォルダはパスに含まれません。データやアーカイブしたコードにだけ使ってください。クラスフォルダでは 1 ファイルに 1 メソッドを置きます。小さなモデルは単一の classdef ファイルにしてもかまいません。

Placement rules for new files新しいファイルの配置ルール

What are you adding?追加するものPut it in置き場所
A new generator, load, branch, or controller model新しい発電機・負荷・ブランチ・制御器のモデル→_GUILDAobject/+<package>/the matching package; make a sub-package when a family of models shares a base class. See Model Implementation.対応するパッケージ。基底クラスを共有するモデル群にはサブパッケージを作ります。モデルの実装 を参照してください。
A new network template新しいネットワークテンプレート→_GUILDAobject/+network/@Name/with bus/, branch/, component/<key>/ data folders, loaded by PowerNetwork.import_csv(dir, Network=obj). network/ (base values Hz, baseMVA in parameter.csv) is optional: without it the defaults apply. A network built in code can be a single file _GUILDAobject/+network/Name.m.bus/、branch/、component/<key>/ のデータフォルダを持ち、PowerNetwork.import_csv(dir, Network=obj) で読み込みます。network/（parameter.csv に基準値 Hz、baseMVA）は省略でき、ない場合は既定値が使われます。コードで組み立てるネットワークは単一ファイル _GUILDAobject/+network/Name.m にできます。

Legacy and archived folders旧フォルダとアーカイブ

Retired code kept for reference goes into a folder named archive/ next to its original location. Having no @ or + prefix, it stays off the MATLAB path inside class and package folders. Do not use any other name or marker for retired or unfinished code.

参照用に残す廃止コードは、元の場所の隣に置いた archive/ という名前のフォルダに入れます。@ や + の接頭辞がないため、クラスフォルダやパッケージフォルダの中では MATLAB パスに含まれません。廃止したコードや未完成のコードに、これ以外の名前や目印を使わないでください。
