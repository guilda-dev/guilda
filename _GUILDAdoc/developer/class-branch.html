Class: クラス: Branch

The abstract base of lines and transformers between two buses. A branch holds its constants and limits and computes its own 2×2 admittance matrix, which the network sums into the bus admittance matrix.

2 母線を結ぶ送電線と変圧器の抽象基底クラスです。ブランチは自身の定数と制限を持ち、2×2 のアドミタンス行列を自分で計算します。ネットワークはそれを足し合わせて母線アドミタンス行列を作ります。

Role役割

A Branch owns R, X, C, tap, phase, its OPF flow limits, and drawing data, and it decides how they form an admittance matrix (the subclass contract get_admittance_matrix). It refers to its two end buses but is not their parent and does not own their voltages: the end voltages and currents it shows are derived from the buses. A branch has no states and no function-handle cache, and it plays no part in the simulation other than through the admittance matrix built when an analysis starts. Branches are created only by PowerNetwork.add_branch.

Branch は R、X、C、tap、phase、OPF の潮流制限、描画データを持ち、それらからアドミタンス行列をどう作るかを決めます（サブクラスの契約 get_admittance_matrix）。両端の母線を参照しますが、その親ではなく電圧も持ちません。表示する端の電圧・電流は母線から導く派生値です。ブランチには状態も関数ハンドルのキャッシュもなく、解析開始時に作られるアドミタンス行列を通してのみ時間応答シミュレーションに関わります。ブランチは PowerNetwork.add_branch でだけ作られます。

A bus with branches cannot be removed alone: remove_bus stops unless RemoveBranches=true, so a branch never keeps a dangling end.

ブランチを持つ母線だけを削除することはできません。remove_bus は RemoveBranches=true でなければ止まるため、ブランチの端が宙に浮くことはありません。
