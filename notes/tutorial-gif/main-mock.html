GUILDA Tutorial

GUILDA is a MATLAB tool for building power system models and running analyses such as power flow, time-domain simulation, approximate linearization, optimal power flow and continuation power flow. This file is the table of contents of the Live Scripts in the _GUILDAtutorial folder. GUILDA.tutorial() opens it again at any time.

Getting started: in MATLAB, go to the GUILDA folder and run GUILDA (it adds the paths), then open a Live Script from the links in the tables below and run it from top to bottom. Every Live Script builds or loads its own network first, so any of them can be opened on its own.

Basic workflow of GUILDA

An analysis in GUILDA builds (or loads) a network, finds and initializes the operating point, adds controllers if needed, then goes on to time-domain simulation, approximate linearization, continuation power flow, optimal power flow and other analyses. Each Step explains one part of this flow in detail.

Contents

There are two kinds of Live Scripts. The Steps (usage manual) cover the features of GUILDA. The Parts (texts on analysis) teach the background of power system analysis while computing it with GUILDA; they go with the lecture notes and the video lectures.

  • New to GUILDA? Read from Step 1. Steps 1-4 take you from building a network to a power flow.
  • Want the background of the analyses? Read from Part 0, with its knowledge page.
  • Know the feature you need? Open only that Step.

Try it first

Load the bundled IEEE 9-bus system and draw its network diagram. A bundled network comes with its equilibrium, so the diagram shows the power flow.

net = network.IEEE9bus(); G = net.plot_diagram();
