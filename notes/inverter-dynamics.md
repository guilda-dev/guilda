# フェーザ解析での GFM/GFL インバータのダイナミクスの調査

> 当時の調査記録です。基準は `refactor/design-alignment` の `8a8d03f7`、日付は 2026-11-24 です。以後の変更は本文に反映しません。コードは変更していません。実装は未着手です。

- **[推測・未確認]** 一般的な知識や記憶に基づくことで、文献やコードの実行では確かめていないこと。

## 1. 結論

フェーザ(RMS)解析の GUILDA でも、GFM/GFL インバータの制御のダイナミクスは実装できます。GUILDA は送電網を代数方程式 I = Y V で表すので、扱えるのは数 Hz〜十数 Hz 程度までの時間スケールの動特性に限ります。PSS/E や PowerFactory の RMS モデル、WECC の汎用モデルと同じ考え方です。[推測・未確認: 商用ツールと WECC モデルの粒度は一般的な知識によります]

## 2. 時間スケールとフェーザで表せる範囲

| 動特性 | 帯域の目安 | フェーザで表せるか |
|---|---|---|
| PWM・スイッチング・高調波 | kHz 以上 | 不可(平均化で無視) |
| LCL フィルタの共振 | 数百 Hz〜kHz | 不可 |
| 電流制御ループ | 数百 Hz〜1 kHz | 代数式か 1 次遅れで近似 |
| 電圧制御ループ(GFM) | 数十〜数百 Hz | 近似すれば可(境界) |
| PLL(GFL) | 数〜数十 Hz | 可(弱系統では境界) |
| P/Q 制御・ドループ・仮想慣性・直流リンク | 0.1〜数 Hz | 可(主な対象) |

[推測・未確認: 帯域は一般的な目安で、機器と文献で異なります]

- 送電線のインダクタンスの動特性を無視しているので、それと同じくらい速いインバータのループを詳しく書いても精度は上がりません。
- GUILDA は正相のみの平衡モデルなので、不平衡と負相電流の制御は扱えません。[推測・未確認: 送電網が正相の単相等価で表されていることからの判断で、コードでは確かめていません]

## 3. GFL で実装できるダイナミクス

[推測・未確認: 一般的なモデル化の知識によります]

- **PLL**: 端子電圧の q 軸成分 V_q を 0 にする PI 制御で、状態は 2 個程度です。弱系統での不安定化はある程度まで再現できます(数十 Hz を超える現象は再現できません。§6 を見てください)。
- **外側の制御**: P/Q、または直流電圧 Vdc と Q の PI 制御と、測定のフィルタ。
- **電流制御**: 代数式(I = I_ref)か、1 次遅れ T·İ = I_ref − I で近似します。
- **電流制限と FRT**: 有効電流と無効電流のどちらを優先するか、電圧低下時の無効電流の注入。式は滑らかではありません(非平滑)。
- **直流コンデンサと電源**。

WECC の REGC/REEC/REPC 系のモデルがこの粒度です。

## 4. GFM で実装できるダイナミクス

[推測・未確認: 一般的なモデル化の知識によります]

- **ドループ**: ω = ω0 − m_p (P_f − P_ref)。電力の測定の低域通過フィルタ(LPF)が実質の慣性になります。Q-V のドループも同じ形です。
- **VSM/VSG**: M ω̇ = P_ref − P − D ω。
- **dVOC、マッチング制御**。
- **内部の電圧源と仮想インピーダンス、電圧振幅の PI 制御**。
- **電流制限**: 仮想インピーダンスを大きくする方式と電流を飽和させる方式で、過渡安定性が大きく変わります。GFM のモデル化で最も難しいところです。

WECC に GFM の汎用モデル(ドループ型と VSM 型)があるというのは記憶に基づくもので、確かめていません。[推測・未確認]

## 5. GUILDA の現状

[確認済み] 基準 `8a8d03f7` でファイルを読みました。

### 5.1 `_GUILDAobject/+component/+GFMInverter/@VSG_classical`(キー `gfm-vsg-classical`)

- 状態は `delta`, `omega` の 2 個、入力は `Pref`, `Vref`、パラメータは `M`, `D`, `Xd`, `Xq`, `alpha` です(`VSG_classical.m`)。
- 古典モデルの発電機と同じ動揺方程式で、電流を `alpha` だけ回して母線へ入れます。動揺方程式の電力は回す前の仮想電力 P̃ です(`fcn_dx.m`、経緯は [vsg-virtual-power.md](vsg-virtual-power.md))。
- クラスの説明に「The inverter internals and the inner control loops are not modeled.」とあり、インバータの内部と内側のループはモデル化していません。

### 5.2 `_GUILDAobject/+component/+GFLInverter/@Static`(キー `gfl-static`)

- 状態は 0 個、入力は `Pref`, `Qref` で、電圧によらず一定の電力を注入します(I = conj((Pref + jQref)/V)、`Static.m`)。
- 内部と内側のループはモデル化していません(クラスの説明による)。

### 5.3 `_GUILDAobject/+component/未+GFM/`(未完成)

- フォルダ名の `未` のため MATLAB のパッケージとしては使えず、中のクラスは古い名前 `component.GFM.*` を継承しています。インタフェースも古い形(`get_nx`, `get_dx_constraint`, `naming_state`)で、現行の `fcn_dx` / `fcn_I` / `Jacobi_*` の形ではありません。
- `Inverter.m`(`Component` を継承): LC フィルタの dq の状態 6 個(`is_dq`, `v_dq`, `i_dq`)に、制御器・基準モデル・直流電源の状態を足します(`get_nx`)。フィルタの式は `d_isdq`, `d_vdq`, `d_idq` で、パラメータは `Inverter.csv`(R, L, C, L_g, R_g, n)です。Sbase・Vbase から基準量を計算する仕組み(`calc_base`)があります。
- `+controller/low_level_cascade.m`: 電圧と電流の 2 段の PI 制御で、状態 4 個です。パラメータは `low_level_cascade.csv`(Kv_p, Kv_i, Ki_p, Ki_i, iac_max)。
- `+ReferenceModel/`: `droop.m`(状態 2)、`vsm.m`(状態 3)、`vsm1axis.m`(状態 4)。`dVOC.csv` と `matching.csv` はパラメータだけで、`.m` はありません。
- `+DCsource/`: `Vconstant.m`(一定電圧)と `Delay1order_model.m`(1 次遅れ、状態 2)。
- 組み合わせのクラス: `droop.m`, `droop_DC1order.m`, `droop_DCconst.m`, `vsm_DC1order.m`, `vsm_DCconst.m`, `vsm1axis_DCconst.m`。

[推測・未確認] 送電網は代数式なのに、フィルタを EMT の粒度(インダクタとコンデンサの微分方程式)で書いているので、時間スケールが合わず、方程式が stiff になるおそれがあります。実行して確かめてはいません。

## 6. 方針の案

[未決] 以下は案で、ユーザーの決定はまだです。

- **推奨**: 内側のループを代数式か 1 次遅れで近似し、ブロックを段階的に足します。
  - GFL: PLL + P/Q 制御 + 電流の 1 次遅れ + 電流制限で、状態 4〜6 個程度。
  - GFM: ドループ/VSM + 電力のフィルタ + 電圧制御 + 仮想インピーダンス + 電流制限で、状態 3〜6 個程度。
  - 既存の線形化・縮約・寄与度の抽出がそのまま使えます。
- `未+GFM` の方式(フィルタを EMT の粒度で書く)は、送電網の動特性も入れる拡張を前提にしない限り勧めません。
- 電流制限を滑らかな関数で近似するか、イベントで切り替えるか(線形化とヘッセ行列に影響します)。[未決]
- PLL の不安定は数十 Hz を超えると EMT が必要なので、ドキュメントに再現できる範囲を明記します。
